# Entrées publiques MeteoVoid

## Page d'arrivée

La page d'arrivée publique est `accueil.html`.

Rôle : présenter MeteoVoid, expliquer le prototype, orienter vers Belgique live, Europe, les pays et les pages de transparence.

## Tableau Belgique live

Le tableau opérationnel Belgique est `index.html`.

Rôle : afficher les modules live avec navigation par onglets : veille, carte, prochaines heures, bulletin, chaleur, réseau, expert et méthode.

## Règle UX

`accueil.html` ne doit pas devenir un second tableau de bord complet.
`index.html` ne doit pas redevenir une page d'arrivée.

Cela évite que deux pages racontent la même chose et rende la visite confuse.
