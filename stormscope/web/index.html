Comment se lit une bascule

L'énergie se charge

Chaleur et humidité empilent du CAPE dans les basses couches.

Le couvercle retient

Une couche d'inhibition (CIN) empêche le déclenchement — l'énergie s'accumule sous pression.

La percée

Quand le forçage dépasse le couvercle, l'atmosphère bascule : le moment que MeteoVoid anticipe.
